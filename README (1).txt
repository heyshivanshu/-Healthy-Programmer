# Healthy Programmer

Healthy Programmer is a Python reminder application that encourages better work habits during long computer sessions. It reminds users to drink water, rest their eyes, and perform light physical activity at regular intervals.

## Features
- Water reminder with sound alert
- Eye relaxation reminder
- Exercise reminder with audio
- Automatic activity logs with timestamps
- Built using Python and Pygame

## How to Run
1. Install pygame:
   pip install pygame

2. Place the MP3 files in the project folder.

3. Run:
   python healthy_programmer.py

## Files
- healthy_programmer.py : Main program
- time_to_drink_water.mp3 : Water reminder
- exercise.mp3 : Exercise reminder
- eyes.mp3 : Eye reminder
- wtr.txt / ex.txt / eye.txt : Activity logs

Created as a beginner Python project.

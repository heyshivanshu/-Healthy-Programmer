# Healthy Programmer

## Problem Statement

People who spend long hours working, studying, programming, or using a computer can easily forget basic health habits such as drinking water, resting their eyes, and taking short physical breaks.

The **Healthy Programmer** project is designed to solve this problem by providing automatic reminders while the user is working on a computer. The application reminds the user to drink water, take an eye break, and perform a short physical activity. It also provides audio notifications and records reminder times.

## Project Scope

The project focuses on providing a simple and lightweight desktop reminder system for people who spend extended periods of time using a computer.

The current scope of the project includes:

- Water intake reminders
- Eye-rest reminders
- Exercise reminders
- Audio notifications for reminders
- Recording reminder timestamps

The project is intended to encourage healthy breaks during computer usage. It is not intended to provide medical diagnosis, treatment, or professional health advice.

## Target Users

The project is mainly intended for:

- Students who study for long hours on computers
- Programmers and software developers
- Office employees
- People working from home
- Other computer users who spend long periods in front of a screen

## High-Level Features

### 1. Water Reminder
Reminds the user to drink water at regular intervals while using the computer.

### 2. Eye-Rest Reminder
Reminds the user to take a break from continuous screen usage and rest their eyes.

### 3. Exercise Reminder
Reminds the user to take a short physical break and perform some exercise.

### 4. Audio Notifications
Uses audio alerts to notify the user when a reminder is triggered.

### 5. Reminder Logging
Records the time at which reminder events occur, allowing reminder activity to be tracked.

## Technology Used

- Python
- Python modules/libraries used in the project
- Audio files/resources
- File-based logging

## Project Goal

The main goal of Healthy Programmer is to turn a simple everyday problem into a practical software solution. Instead of requiring the user to remember when to take breaks, the application handles the reminders automatically while the user continues their normal computer work.

# Healthy Programmer

Healthy Programmer is a Python reminder application that encourages better work habits during long computer sessions. It reminds users to drink water, rest their eyes, and perform light physical activity at regular intervals.

## Features

* Water reminder with sound alert
* Eye relaxation reminder
* Exercise reminder with audio
* Automatic activity logs with timestamps
* Built using Python and Pygame

## Requirements

* Python **3.13**
* Pygame **2.6.1**

Install the required dependency:

```bash
pip install -r requirements.txt
```

## How to Run

1. Download or clone this repository.
2. Open **Command Prompt** and navigate to the project folder:

   ```bash
   cd path\to\Healthy-Programmer
   ```
3. Install the required package:

   ```bash
   pip install -r requirements.txt
   ```
4. Make sure all MP3 reminder files are in the project folder.
5. Run the program:

   ```bash
   python project.py
   ```

   If `python` doesn't work, use:

   ```bash
   py -3.13 project.py
   ```

## Project Structure

* `project.py` — Main program
* `requirements.txt` — Project dependencies
* `water.mp3` — Water reminder sound
* `eyes.mp3` — Eye reminder sound
* `physical.mp3` — Exercise reminder sound
* `wtr.txt` — Water log
* `eye.txt` — Eye log
* `ex.txt` — Exercise log

Created as a beginner Python project using **Python 3.13** and **Pygame 2.6.1**.
